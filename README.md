# ⛵ 帆船赛自动裁判系统

基于世界帆船竞赛规则（RRS 2021–2024 第 2 部分）的实时判罚引擎与可视化平台。
引擎用 **TypeScript** 编写，逐帧评估两船相遇，自动判出条款号、犯规船、权利船与免责关系，
并跟踪 720° 罚转解脱、赛后扣分与抗议申诉回放。

## 核心能力

### 判罚引擎（`src/engine/`，纯函数、零 DOM 依赖）

| 模块 | 实现条款 | 说明 |
| --- | --- | --- |
| `rules.ts` | RRS 10 / 11 / 12 / 13 | A 节航行权：左右舷、上下风、前后船、换舷中 |
| `rulesMeta.ts` | RRS 10–20、21(a)、44.2 | 条款号、中文名称、条文要点 |
| `rules.ts` | RRS 18.2(b)/(e)、18.3 | 绕标区、绕标空间、上风标换舷限制 |
| `rules.ts` | RRS 19.2 | 障碍物旁的通过空间 |
| `rules.ts` | RRS 20 | 呼救换舷空间（`tack` / `youTack`） |
| `rules.ts` | RRS 14、21(a) | 避免接触、权利方免责 |
| `penaltyTracker.ts` | RRS 44.2 | 720° 两圈旋转（含一次 tack + 一次 gybe），未完成则扣分 |
| `protest.ts` | 抗议流程 | 申诉提起、复核、维持/撤销罚转 |
| `replayBuffer.ts` | — | 环形缓冲，按事件截取犯规前后 ±3 秒船位 |

每帧输出 `Incident`（条款号、犯规船、权利船、附带条款、免责船、距离、原因）与
`PairRelation`（左右舷、上下风、前后、相联、接触、绕标区归属），供 Canvas 标注。

### 性能

- 8 船规模下 `RulesEngine.step` 平均 **≈0.02 ms/帧**、p95 < 0.1 ms（见 `perf.test.ts`），
  远低于 1 ms 预算。热路径只有配对循环与向量运算，无堆分配。

### 规则用例（100 个，`src/cases/` + `src/testkit/`）

按常见犯规情形构造的确定性场景，覆盖 9 大类：

- RRS10 左右舷（14）、RRS11 上下风（12）、RRS12 前后船（8）、RRS13 换舷（8）
- RRS14 避免接触（4）、RRS18 绕标区（18）、RRS19 障碍物（8）、RRS20 呼救（6）
- 干净/合规场景（9）、多船与边界（13）

每个用例用关键帧 DSL 描述船位/航向序列，断言条款号、犯规船、权利船、附带条款与免责船。
**当前判对率 100/100 = 100%（门槛 ≥95%）。**

## 四个页面（`src/ui/`，Vite + Canvas，hash 路由）

1. **比赛页**：Canvas 实时绘制船舶（航向/受风舷）、标志绕标区、来风方向、两船相对位置、
   接触高亮与权利关系；支持播放/暂停/拖动时间轴，侧栏显示当前判罚与 720° 罚转进度。
2. **判罚记录页**：全部犯规事件表（条款、犯规/权利船、距离、原因）、罚转与扣分明细、条款速查。
3. **申诉页**：选择犯规后回放犯规前后 ±3 秒船位，可做出「撤销判罚 / 维持原判」复核。
4. **规则用例页**：100 个用例分类展示，实时显示每个用例的引擎判罚与期望比对结果。

## 工程约定

- 角度：从北顺时针 0–360°；世界坐标 y 轴向北。
- `windDir` 表示**来风方向**（水手口径，0=北风）；上风 = 靠近来风方向。
- 接触阈值 = 两船半船长之和；非接触妨碍要求两船进入安全距离（阈值 ×1.6）且距离持续缩短。
- 几何构造器 `src/testkit/geometryBuilder.ts` 在局部坐标系中程序化生成相联/汇聚轨迹，
  保证测试用例在数学上满足相联、入区、接触等前提。

## 已知简化

- RRS 18.2(e) 假定外侧船在相联建立时始终有空间可给；未建模船帆空气动力学与浪涌。
- RRS 13 两船同时换舷的罕见情形不区分先后。
- 船只视为平面圆点 + 朝向，未做多边形碰撞。
